# **RAW智能图库开发策划书**

**——比Adobe Bridge更轻量、比小米相册更专业的RAW管理工具**

------

## **一、市场洞察与产品定位**

### **1.1 现有产品痛点分析**

| 产品         | 优势                  | 劣势                 | 用户需求缺口                   |
| ------------ | --------------------- | -------------------- | ------------------------------ |
| Adobe Bridge | 专业、元数据全面      | 功能臃肿、学习成本高 | 轻量化、快速操作               |
| 小米相册     | 便捷分类              | 无PC端、RAW支持有限  | 跨设备同步+专业RAW管理         |
| 竞品空白区   | 支持PC端+EXIF修改备份 | 无针对性解决方案     | 一站式RAW文件管理+便捷EXIF调整 |

**核心价值主张**：

- **轻量化**：启动速度比Bridge快3倍（通过智能缓存+按需解码技术）
- **智能+专业**：AI自动分类+手动精细调整的双重保障
- **跨平台同步**：PC/Mac/手机无缝衔接

------

## **二、核心功能设计**

### **2.1 AI智能整理工具箱**

| **功能模块**     | **技术实现逻辑**                                             | **用户价值**                                                 |
| ---------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **智能分类引擎** | 基于深度学习（TensorFlow）的物体/场景识别 + EXIF日期/地点解析 | 自动将"海岸风光"分类到对应文件夹，无需手动拖拽               |
| **智能重命名**   | 支持自定义模板： 例如"{拍摄日期}*{设备型号}*{关键人物识别}"  | 一键从"IMG_1234.CR2"变为"2025-05-20_NikonD850_张三.jpg"（自动生成备份） |
| **相似照片清理** | 基于感知哈希（pHash）算法比对相似度                          | 一键删除构图/内容重复项，节省50%存储空间                     |
| **位置地图视图** | 调用Google Maps API将GPS坐标转为可视化地图                   | 直观查看"云南自驾行"所有拍摄点位分布                         |

### **2.2 EXIF全维度管理**

| **操作权限** | **具体功能**                                                 | **技术实现注意事项**                                     |
| ------------ | ------------------------------------------------------------ | -------------------------------------------------------- |
| **可编辑项** | - 手动修改拍摄日期/时间（同步调整全部选中的RAW） - 追加自定义标签 - 批量擦除位置隐私 | 使用ExifTool库确保跨平台一致性，关键操作自动创建版本快照 |
| **备份机制** | 导出EXIF变更日志（JSON格式），支持一键还原到任意历史版本     | 采用差分存储节省空间，版本保留30天（付费可延长）         |
| **隐私保护** | 一键清除设备型号/镜头信息（满足商业摄影需求）                | 算法精确擦除特定标签而不破坏文件结构                     |

## **三、核心优势构建**

### **3.1 对比竞品差异化优势**

| **对比维度** | **Bridge** | **小米相册**   | **RAW图库**（我们的产品）          |
| ------------ | ---------- | -------------- | ---------------------------------- |
| 设备覆盖     | 仅PC端     | 仅移动端       | 全平台（PC+Mac+手机）              |
| EXIF功能     | 仅预览     | 可编辑但无备份 | **可编辑+一键备份+版本回溯**       |
| AI智能程度   | 基础分类   | 简单标签       | **多模态AI（物体+场景+地理位置）** |
| 文件整理     | 需手动操作 | 简单分类       | **自动整理+智能冲突解决**          |

## **四、技术实现路径**

### **4.1 关键技术栈**

- 

  跨平台框架

  ：

  - 桌面端：Electron（复用Web技术栈，降低开发成本）
  - 移动端：Flutter + Dart（高性能跨平台UI）

- 

  AI处理管线

  ：

  ```
  graph LR
    A[图像数据] --> B{分辨率检测}
    B --> |>20MB| C[降低分辨率预处理]
    B --> |<20MB| D[原图处理]
    C --> E[TensorFlow模型推理]
    D --> E
    E --> F[结果写入本地数据库]
  ```

- **EXIF处理引擎**：集成ExifTool + 自定义私有协议校验（防止数据损坏）

## **六、用户验证与MVP设计**

### **6.1 关键验证指标**

1. 用户完成首次分类整理的平均时长（目标：<3分钟）
2. EXIF修改后版本冲突发生率（目标：<0.1%）
3. 跨设备同步速度（局域网<10秒/千张图片）

### **6.2 场景化测试用例**

- **职业摄影师场景**：
   导入1000张婚摄RAW → AI自动按"新娘/新郎/场地"分类 → 修改错误时间后批量同步云端
- **家庭用户场景**：
   从手机导入旅行照片 → 地图视图定位拍摄地点 → 删除重复的自拍

------

## **七、风险控制**

### **7.1 数据安全风险**

- 关键措施：
  1. 本地加密存储（AES-256）
  2. 传输层TLS 1.3加密
  3. 每日异地备份（多地容灾）

### **7.2 兼容性风险**

- 建立主流相机型号测试矩阵（每月更新）
- 预留手动修复工具包（支持RawTherapee格式）
