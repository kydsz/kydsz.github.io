## virtualenv虚拟机

安装命令

```shell
apt install python3-virtualenv
```

创建虚拟机

```shell
virtualenv env
```

注：env为虚拟机名

启动虚拟机

```shell
source env/bin/activate
```

关闭虚拟机命令

```shell
deactivate
```
