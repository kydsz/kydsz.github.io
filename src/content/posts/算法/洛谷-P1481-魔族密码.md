> 前缀词链：用哈希表统计每个前缀的出现次数，对每个词累加其所有前缀的计数，取最大值即最长词链长度。

## 哈希 

## 字符串

```c++
#include <iostream>
#include <vector>
#include <map>
using namespace std;
vector<string> a;
map<string, int> dict;


int main() {
    int n, ans = 0;

    cin >> n;
    a.resize(n);
    for (int i = 0; i < n; ++i) {
        cin >> a[i];
        dict[a[i]]++;
    }

    for (int i = 0; i < n; ++i) {
        int cut = 0;
        string s = a[i] ,t;
        for (int j = 0; j < s.length(); ++j) {
            t += s[j];
            cut += dict[t];
        }
        ans = max(ans, cut);
    }
    cout << ans;
    return 0;
}
```
