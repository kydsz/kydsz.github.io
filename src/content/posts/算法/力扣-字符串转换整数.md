> 字符串转整数：跳过前导空格并判断正负号，逐位累乘 10 构造结果，用 INT_MAX/10 预判溢出（另附 stringstream 简化版）。

```c++
class Solution {
public:
    int myAtoi(string s) {
        stringstream liu(s);
        int n=0;
        liu>>n;
        return n;
    }
};

/**
该代码是实现字符串到整数的转换函数 myAtoi。

主要分析:

使用字符串流stringstream来解析字符串
stringstream是一个包装C++流的类,用于读写字符串。可以把字符串看成一个输入流进行解析。

构造字符串流对象liu,传入要解析的字符串s

定义一个int类型的变量n来保存转换后的整数

使用提取运算符>>从字符串流中直接提取第一个整数到变量n中

返回转换后的整数n

具体实现过程:

构造字符串流对象liu,它以只读模式打开字符串s
运算符尝试从liu中提取第一个整数,并赋值给n

此时liu将不再包含任何后续的非数字字符
n保存了字符串开头的第一个整数值
返回n,完成了字符串到整数的转换
字符串流提供了一种简单易读的方式来实现字符串和基本数据类型之间的转换。它会自动识别字符串开头的数字,忽略后续非数字部分,完成atoi功能。

该代码实现了一个简化版本的字符串到整数转换,没有考虑处理异常情况如无效字符等,但提供了底层思路。
 */
```

```c++
class Solution {
public:
    int myAtoi(string s) {
        int res = 0, bndry = INT_MAX / 10;
        int i = 0, sign = 1, length = s.size();
        if(length == 0) return 0;
        while(s[i] == ' ')
            if(++i == length) return 0;
        if(s[i] == '-') sign = -1;
        if(s[i] == '-' || s[i] == '+') i++;
        for(int j = i; j < length; j++) {
            if(s[j] < '0' || s[j] > '9') break;
            if(res > bndry || res == bndry && s[j] > '7')
                return sign == 1 ? INT_MAX : INT_MIN;
            res = res * 10 + (s[j] - '0');
        }
        return sign * res;
    }
};
```
