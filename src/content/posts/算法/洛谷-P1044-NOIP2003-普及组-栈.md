> 卡特兰数：n 个数进出栈的出栈序列总数为卡特兰数，用递推式 f[n]=f[n-1]*(4n-2)/(n+1) 计算。

## 卡塔兰数

```c++
#include <iostream>

using namespace std;

int Catalan(int n) {
    int f[10000];
    f[0] = f[1] = 1;
    for (int i = 2; i <= n; i++) {
        // f[n]=f[0]∗f[n−1]+f[1]∗f[n−2]+...+f[n−1]∗f[0](n≥2)
        f[i] += f[i - 1] * (4 * i - 2) / (i + 1);
    }
    return f[n];
}

int n;
int main() {
    cin >> n;
    cout << Catalan(n);
    return 0;
}
```
