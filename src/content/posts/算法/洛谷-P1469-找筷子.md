> 位运算：相同数异或为 0，所有长度依次异或后成对的都被消去，剩下的就是唯一落单的筷子。

### 位运算

```c++
#include <bits/stdc++.h>

using namespace std;

int main() {
    int n, ans = 0, m;
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n;
    for (int i = 0; i < n; ++i) {
        cin >> m;
        ans ^= m; // 核心
    }
    cout << ans;
    return 0;
}
```
