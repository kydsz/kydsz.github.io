> 互质：用 gcd 筛出 [1,n) 内与 n 互质的数存表，互质数按 n 为周期重复，第 k 个由 (k-1)/cut*n+arr[k%cut] 直接算出。

## 互质	欧拉函数

```c++
#include <iostream>

using namespace std;
long n, k, cut = 0;
long arr[10000000];

long gcd(long a, long b) {
    return b == 0 ? a : gcd(b, a % b);
}

int main() {
    cin >> n >> k;
    for (long i = 1; i < n; ++i) {
        if (gcd(i, n) == 1) {
            arr[++cut] = i;
        }
    }
    cout << (k - 1) / cut * n + arr[k % cut];
    return 0;
}
```
