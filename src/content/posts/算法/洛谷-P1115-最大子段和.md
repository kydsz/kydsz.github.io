> 最大子段和：线性扫描，f[i]=max(a[i], f[i-1]+a[i]) 维护以 i 结尾的最大子段和，答案取全程最大值。

DP

``` c++
#include<bits/stdc++.h>

using namespace std;
int n, a, b, ans = INT_MIN;

int main() {
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a;
        if (i == 1) b = a;
        else b = max(a, a + b);
        ans = max(ans, b);
    }
    cout << ans;
    return 0;
}
```
